Visualizing service boundaries with interactive polygon overlays

✨ New Feature: Service Area Polygon Overlays

When service areas are configured, the map now displays the actual administrative boundaries as semi-transparent polygon overlays. This helps users understand exactly which geographic areas are being searched.

🎯 What you'll see:

  • Blue dashed polygons showing the exact boundaries of configured service areas
  • Interactive popups when you click on the polygon boundaries
  • Automatic map fitting to show all configured service areas
  • Service filtering - only services within the polygon boundaries are shown

💡 Technical Details

  • Data Source: ALISS Service Areas API (v5)
  • Format: GeoJSON polygons from administrative boundaries
  • Rendering: Leaflet.js polygon overlays with custom styling
  • Performance: Boundaries cached after first load
